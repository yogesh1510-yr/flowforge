# FlowForge

**Real-Time Order Intelligence Platform**

FlowForge is a learning and engineering project focused on building a real-time order intelligence platform using event-driven architecture, change data capture (CDC), streaming, analytics, and containerized services.

## Project Goals

- Build a containerized foundation using Docker Compose.
- Develop an API using FastAPI.
- Use PostgreSQL for operational and analytical data.
- Introduce Kafka and Debezium for change data capture and event streaming.
- Process data using Python and Spark.
- Orchestrate analytics workflows using Airflow.
